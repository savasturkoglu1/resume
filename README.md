## Çalıştırma

Bağımlılık yok, derleme yok. Dosyayı doğrudan açmak yeterli:

```bash
open index.html
```

Yerel sunucu tercih edilirse:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
